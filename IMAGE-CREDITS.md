# Image Credits

Real photographs sourced for the 2026 second-pass redesign, stored under
`public/images/araban-nakit-2026/`. All images were downloaded from Wikimedia
Commons or Unsplash, verified for license and content (no graphic accident
scenes, no visible injuries/police, no dominant brand logos, no watermarks),
converted to WebP, and resized. Any image showing a legible license plate was
edited to blur the plate before publishing.

CC BY / CC BY-SA licenses legally require attribution — this file is that
attribution record. If any of these images are used somewhere a per-image
on-page credit is expected, add a small "Photo: Wikimedia Commons" caption
near that image as well.
